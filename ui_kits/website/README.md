# B&D Artes & Impressões — Website UI Kit

## Overview
Interactive prototype of the B&D e-commerce storefront. Includes homepage with hero, product grid, cart drawer, and footer.

## Components
- **Header.jsx** — Sticky nav with search, favorites, account, cart badge
- **ProductCard.jsx** — Product card with hover states, badge, favorite toggle, add to cart
- **CartDrawer.jsx** — Slide-out cart with item list, totals, checkout CTA
- **Footer.jsx** — Dark navy footer with brand, nav columns, tagline
- **index.html** — Full interactive prototype combining all components

## Design Width
1280px desktop. Not responsive (prototype only).

## Brand Notes
- Display type: Playfair Display (serif)
- Body type: DM Sans
- Mono (prices/SKUs): DM Mono
- Primary color: Navy #1D2235
- Brand accent: Blue #BBCFEB
- Rose accent: #D4849A (hearts/favorites)
